# 외주처 생산계획 자동화 - 엑셀 VBA 매크로 사용 가이드

## 1. 설치 방법

### Step 1: 새 엑셀 파일 생성
1. 엑셀을 열고 새 통합 문서 생성
2. **파일 > 다른 이름으로 저장**
3. 파일 형식: **Excel 매크로 사용 통합 문서 (*.xlsm)** 선택
4. 파일명: `생산계획_자동화.xlsm` (원하는 이름으로)

### Step 2: VBA 편집기 열기
1. **Alt + F11** 키를 눌러 VBA 편집기 열기
2. 좌측 프로젝트 창에서 **VBAProject (생산계획_자동화.xlsm)** 확인

### Step 3: 모듈 추가 및 코드 붙여넣기
1. 메뉴에서 **삽입 > 모듈** 클릭
2. 우측 코드 창에 `AutoPlanning.bas` 파일의 전체 내용을 붙여넣기
3. **Ctrl + S**로 저장
4. VBA 편집기 닫기 (X 버튼 또는 Alt+Q)

### Step 4: 매크로 보안 설정 (필요시)
1. **파일 > 옵션 > 보안 센터 > 보안 센터 설정**
2. **매크로 설정 > 모든 매크로 포함** 선택 (또는 디지털 서명된 매크로만)
3. 엑셀 재시작

---

## 2. 초기 설정

### Step 1: 초기설정 매크로 실행
1. **Alt + F8** 키를 눌러 매크로 창 열기
2. `초기설정` 선택 후 **실행** 클릭
3. 3개의 시트가 자동 생성됨:
   - `설정_외주처`: 외주처 정보
   - `설정_고객매칭`: 고객사-외주처 매칭
   - `auto-planning`: 결과 출력 시트

### Step 2: 외주처 설정 확인/수정
`설정_외주처` 시트에서 아래 정보 확인:

| 열 | 설명 | 예시 |
|---|---|---|
| 외주처ID | 시스템 내부 ID | withmom |
| 외주처명 | 표시 이름 | 위드맘 |
| 라인수 | 보유 라인 개수 | 8 |
| 라인당일일생산량 | 라인당 하루 CAPA | 15000 |
| 가능공정 | 콤마로 구분 | normal,shrink,highFrequency |
| 월간목표 | 월 목표 생산량 | 1600000 |
| 우선순위 | 낮을수록 우선 (1=최우선) | 1 |

**가능공정 코드:**
- `normal` = 일반
- `shrink` = 수축
- `mixing` = 교반
- `highFrequency` = 고주파

### Step 3: 고객사-외주처 매칭 설정
`설정_고객매칭` 시트에서 매칭 규칙 설정:

| 고객사코드 | 외주처ID | 우선순위 |
|---|---|---|
| CLO | gram | 1 |
| DPD | withmom | 1 |

- 제품코드에서 3자리 영문코드 추출 (예: `9CLO1360310` → `CLO`)
- 해당 코드가 있으면 지정된 외주처에 우선 배정

---

## 3. 데이터 입력

### Step 1: "계획" 시트 생성
1. 시트 이름을 `계획`으로 변경 (또는 새 시트 추가 후 이름 변경)
2. 아래 컬럼 구조로 데이터 입력:

| 열 | 헤더 | 설명 |
|---|---|---|
| A | 이동일 | 자재를 외주처에 보내는 날 (예: 1/9, 1월 9일) |
| B | 상태 | (선택) |
| C | 특수공정 | 수축, 교반, 고주파 중 하나 (빈값=일반) |
| D | 외주처 | (빈값이면 자동 배정, 값 있으면 유지) |
| E | 담당자 | (선택) |
| F | 제품코드 | **필수** (예: 9CLO1360310) |
| G | 제품명 | 제품 이름 |
| H | 공정 | 충전, 포장, 충포장 등 |
| I | 수량 | **필수** (숫자, 콤마 가능) |
| J | 제조일 | (선택) |
| K | 자재입고 | (선택) |
| L | 납기일 | 납품 기한 |
| M | 긴급 | (선택) |
| N | 야상 | (선택) |
| O | 비고 | (선택) |

### 주의사항
- **제품코드(F열)가 비어있으면 해당 행 무시**
- **수량(I열)이 0이거나 비어있으면 해당 행 무시**
- **이동일(A열)이 "미정"이거나 비어있으면 해당 행 무시**
- 첫 번째 행은 헤더로 인식 (데이터는 2행부터)

---

## 4. 자동 배정 실행

### Step 1: 매크로 실행
1. **Alt + F8** 키를 눌러 매크로 창 열기
2. `자동배정실행` 선택 후 **실행** 클릭
3. 처리 완료 메시지 확인

### Step 2: 결과 확인
`auto-planning` 시트에 결과가 출력됨:

**상단 대시보드:**
- 총 품목 수
- 총 생산량
- 배정 외주처 수
- 품목당 평균 수량
- 외주처별 배분 현황 (수량, 목표 대비 달성률)

**하단 생산계획표:**
| No | 제품코드 | 제품명 | 수량 | 외주처 | 라인 | 생산시작일 | 소요일수 | 납기일 | 이동일 | 특수공정 |
|---|---|---|---|---|---|---|---|---|---|---|

- 외주처별로 색상 구분
- "배정불가"는 회색 표시

## 5. 배정 로직 설명

### 배정 우선순위
1. **D열에 이미 외주처가 입력되어 있으면** → 그대로 유지
2. **고객사 매칭 확인** → 제품코드에서 추출한 3자리 코드로 매칭된 외주처 확인
3. **특수공정 가능 여부** → 수축/교반/고주파 등 처리 가능한 외주처 필터링
4. **우선순위 기반 선택** → 설정된 우선순위(1=최우선)에 따라 선택
5. **월간 목표 고려** → 같은 우선순위면 월간 목표가 높은 외주처 우선

### 생산 시작일 계산
- **이동일 + 1 근무일** = 생산 시작일
- 주말(토/일)은 근무일에서 제외
- 예: 이동일이 금요일(1/10)이면 → 생산 시작일은 월요일(1/13)

### 소요일수 계산
- `소요일수 = 올림(수량 ÷ 라인당일일생산량)`
- 예: 수량 25,000개, CAPA 15,000개/일 → 2일 소요

### 라인 배정
- 각 외주처의 라인별로 일정 확인
- 연속된 빈 날짜가 있는 라인에 배정
- 한 라인에 하루 한 품목만 배치 (라인 교체 시간 고려)

## 6. 버튼 추가 (선택사항)

편의를 위해 시트에 버튼을 추가할 수 있습니다:

1. **개발 도구 탭 > 삽입 > 양식 컨트롤 > 버튼** 클릭
2. 시트에 드래그하여 버튼 생성
3. 매크로 지정 창에서 `자동배정실행` 선택
4. 버튼 텍스트를 "자동 배정 실행"으로 변경

## 7. 문제 해결

### "매크로를 찾을 수 없습니다"
- 파일이 `.xlsm` 형식으로 저장되었는지 확인
- VBA 편집기에서 모듈이 제대로 추가되었는지 확인

### "설정을 로드할 수 없습니다"
- `초기설정` 매크로를 먼저 실행했는지 확인
- `설정_외주처`, `설정_고객매칭` 시트가 있는지 확인

### "처리할 데이터가 없습니다"
- `계획` 시트가 있는지 확인
- 제품코드(F열)와 수량(I열)이 입력되어 있는지 확인
- 이동일(A열)이 "미정"이 아닌지 확인

### 배정이 안 되는 품목
- 특수공정(수축/교반/고주파)을 처리할 수 있는 외주처가 있는지 확인
- `설정_외주처`에서 해당 공정이 `가능공정` 컬럼에 포함되어 있는지 확인

## 9. 팁

1. **설정 백업**: `설정_외주처`, `설정_고객매칭` 시트를 다른 파일에 복사해두면 재사용 가능
2. **결과 보존**: `auto-planning` 시트를 복사하여 날짜별로 이름 변경 (예: `auto-planning_0115`)
3. **빠른 실행**: 자주 사용하는 매크로는 빠른 실행 도구 모음에 추가
