# 1. 현황 및 문제점

## 현재 외주 생산계획 수립 프로세스

<br>

### 업무 흐름
```
메신저로 물량 수신 → 엑셀 수작업 입력 → 업체별 수동 배정 
    → 날짜 계산 → 업체별 개별 연락 → 변경사항 재작업
```

<br>

### 소요 시간: **일 평균 2~3시간**

---

# 현재 문제점

| 문제 | 상세 내용 | 영향 |
|------|----------|------|
| **수작업 의존** | 모든 배정을 담당자가 직접 계산 | 업무 과부하 |
| **휴먼 에러** | 날짜 계산 실수, 업체 배정 오류 | 납기 지연 위험 |
| **변경 대응 어려움** | 이동일 변경 시 전체 재계산 필요 | 비효율적 |
| **정보 분산** | 업체별 개별 연락, 이력 관리 불가 | 추적 어려움 |
| **표준화 부재** | 담당자별 다른 방식 | 인수인계 어려움 |

---

# 실제 발생 사례

<br>

### Case 1: 날짜 계산 오류
> 납기 역산 시 주말 미반영 → 이동일 1일 지연 → 납기 miss

<br>

### Case 2: 업체 배정 실수  
> 특수공정(교반) 필요 품목을 처리 불가 업체에 배정 → 재배정 필요

<br>

### Case 3: 변경사항 누락
> 이동일 변경 후 업체 미통보 → 자재 미도착 → 생산 차질

# 2. 해결 방안

## 외주 생산계획 자동화 시스템 구축

<br>

### 핵심 컨셉

| 항목 | Before (현재) | After (자동화) |
|------|--------------|----------------|
| 데이터 입력 | 분산된 엑셀 | **통합 Raw 데이터 시트** |
| 업체 배정 | 수동 판단 | **자동 배정 알고리즘** |
| 날짜 계산 | 수작업 계산 | **자동 역산 (주말 제외)** |
| 업체 통보 | 개별 연락 | **업체별 계획표 자동 생성** |
| 변경 관리 | 전체 재작업 | **변경분만 자동 반영** |

# 3. 시스템 기능

## 3-1. 통합 데이터 관리

<br>

### Raw 데이터 시트 (16개 컬럼)

| 구분 | 컬럼 | 설명 |
|------|------|------|
| **입력 영역** | 품번, 품명, 수량, 납기 등 10개 | 사용자 직접 입력 |
| **자동 영역** | 고객사코드, 배정업체, 이동일 등 6개 | 시스템 자동 생성 |

<br>

### 특징
- 드롭다운 선택 (공정명, 긴급도, 상태)
- 조건부 서식 (상태별 색상 구분)
- 데이터 유효성 검사

---

# 3-2. 자동 역산 로직

<br>

## 납기 기준 자동 날짜 계산

```
납기일 → 생산완료일(D-1) → 생산시작일 → 이동일 → 발주일
```

<br>

### 자동 반영 사항
- **주말 자동 제외** (토/일 건너뛰기)
- **생산 소요일 자동 계산** (수량 ÷ 일일 Capa)
- **긴급도별 Capa 확장** (잔업, 토요특근 반영)

<br>

> **효과: 날짜 계산 실수 원천 차단**

---

# 3-3. 지능형 자동 배정

<br>

## 배정 우선순위 알고리즘

```
1순위: 기존 배정 업체 유지 (이동일만 변경 시)
   ↓
2순위: 고객사 매칭 업체 (설정 기반)
   ↓  
3순위: 우선순위 순 슬롯 검색
   ↓
실패 시: 배정불가 + 대안 업체 리스트 제공
```

<br>

### 자동 체크 사항
- 특수공정 처리 가능 여부 (수축/교반/고주파)
- 라인별 가용 슬롯 확인
- 업체별 월 생산 목표 고려

# 3-4. 경고 시스템

<br>

## 실수 방지를 위한 자동 경고

| 경고 유형 | 조건 | 표시 |
|----------|------|------|
| **공정 불가** | 지정 업체가 특수공정 처리 불가 | 빨간색 강조 |
| **매칭 불일치** | 고객 매칭 설정과 다른 업체 지정 | 주황색 강조 |

<br>

### 예시
> "**위드맘**은 **교반** 공정 처리 불가"  
> → 담당자가 실수로 배정해도 시스템이 경고

<br>

> **효과: 배정 실수 사전 방지**

# 3-5. 확정/조정 구간 관리

<br>

```
오늘   D+1    D+2  │  D+3    D+4    D+5   ...
  │     │      │   │    │      │      │
  ▼     ▼      ▼   │    ▼      ▼      ▼
                   │
  🔒 확정 구간     │   ✏️ 조정 가능 구간
  ───────────────  │   ─────────────────
  • 발주완료=고정  │   • 재배정 가능
  • 변경 시 개별연락│   • 일괄 통보로 커버
```

<br>

> **효과: 발주 후 변경 불가 건 자동 보호**

# 3-6. 업체별 계획표 자동 생성

<br>

## 업체 공유용 계획표 원클릭 생성

| 항목 | 내용 |
|------|------|
| **생성 방식** | 업체별 별도 시트 자동 생성 |
| **포함 정보** | 이동일, 품번, 품명, 수량, 납기, 긴급도 |
| **변경 표시** | 신규 추가/변경 건 하이라이트 |
| **구간 표시** | D+2 확정구간 색상 구분 |

<br>

### 생성 시트 예시
- `리니어_계획표`
- `위드맘_계획표`
- `그램_계획표` ...

# 3-7. 세트품 자동 처리

<br>

## 세트품(반제품 조합) 자동 인식 및 처리

<br>

### 자동 식별 조건
- 공정명: 포장/충포장 또는 충전/충포장
- 연속된 행 + 동일 고객사코드

<br>

### 자동 처리
- **수량 합산** (세트 구성품 전체)
- **Capa 80% 적용** (생산성 하락 반영)
- **동일 업체/동일 이동일** 자동 배정
